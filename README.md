# Claude Pop-Up

A data pack. The first time you join a world, Claude pops up.
You hear a spooky sound, a big title shows, and a villager named Claude
appears in front of you.
If you knock Claude out, he comes back to life after 3 seconds.

## Use it

1. Make a new world.
2. Click **Data Packs**, then drag `claude-popup.zip` into the window.
3. Move it to the right side and make the world.

A data pack only works in the world it was added to.

Made by Elduin. Works in Minecraft 1.21.11 and up.
